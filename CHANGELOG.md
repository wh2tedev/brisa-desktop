# Changelog

## 0.1.0

First working version of Brisa Desktop.

- Tabs, address bar with the same URL rules as Brisa for Android, six search engines.
- HTTPS first with fallback only on connection failure; certificate errors are never bypassable.
- Tracker and ad blocking with Off, Standard and Strict levels, per-site exceptions and a counter.
- Third-party cookie filter, Do Not Track and Global Privacy Control, permissions denied by default.
- Private tabs with an off-the-record profile.
- Bookmarks, optional history, address-bar suggestions computed locally.
- Downloads with confirmation, extra warning for risky file types, download list.
- Settings, dark and light themes, accent colors, pure black, reduced-motion switch.
- Debian package for arm64, CI for arm64 and x86_64.
